# Чек-лист запуска и проверки StudyTrack

Команды даны для PowerShell (Windows). В Git Bash отличается только копирование файлов: `cp` вместо `copy`.

---

## 1. Подготовка (один раз)

- [ ] Установлен Node.js 22 LTS (не ниже 22.12): `node -v`
- [ ] В MongoDB Atlas создан кластер, пользователь базы, в Network Access разрешен доступ
- [ ] Созданы файлы окружения (в git они не попадают):

```powershell
cd C:\StudyTrack\api
copy .env.example .env
```

В `api\.env` заполнить:

| Переменная | Значение |
|---|---|
| `MONGODB_URI` | строка Atlas с базой `/studytrack` |
| `MONGODB_URI_TEST` | та же строка, но с базой `/studytrack_test` |
| `JWT_SECRET` | результат команды ниже |
| `WEB_ORIGIN` | `http://localhost:3000` |

```powershell
node -e "console.log(require('crypto').randomBytes(48).toString('base64url'))"
```

```powershell
cd C:\StudyTrack\web
copy .env.example .env.local
```

В `web\.env.local`: `NEXT_PUBLIC_API_URL=http://localhost:4000`

- [ ] Установлены зависимости:

```powershell

cd C:\StudyTrack\web

```

## 6. Ручная проверка в браузере

Для двух ролей нужны **два профиля браузера** (или обычное окно и окно инкогнито). Вход хранится только в памяти вкладки: после F5 или ручного ввода адреса нужно войти снова. Внутри сайта переходите по ссылкам.

### 6.1. Вход и регистрация

- [ ] Регистрация нового пользователя: попадаем в личный кабинет, роль «Студент»
- [ ] Регистрация с тем же email: ошибка у поля email
- [ ] Пароль короче 10 символов: ошибка у поля, введенные данные не пропали
- [ ] Вход с неверным паролем и с несуществующим email: одно и то же сообщение
- [ ] Кнопка «Войти» блокируется, пока идет запрос (двойной клик не отправляет форму дважды)
- [ ] «Выйти»: возврат на главную, закрытые страницы показывают «Нужно войти»
- [ ] F5 на закрытой странице: «Нужно войти» (так и задумано по ТЗ)

### 6.2. Роли и чужие объекты

- [ ] Студент открывает `/courses/new`, `/categories`, `/grading`: «Нет доступа»
- [ ] Олег Иванов (чужой преподаватель) открывает ссылку на курс Анны: «Курс не найден или у вас нет к нему доступа»
- [ ] Посторонний открывает ссылку на курс или работу: «не найден», текст работы не виден
- [ ] Навигация в шапке разная у преподавателя и студента

### 6.3. Категории (Анна)

- [ ] Создать категорию и подкатегорию: появились в таблице с полным путем
- [ ] Категорию с таким же именем в том же разделе создать нельзя (ошибка у поля)
- [ ] Пустую свою категорию можно удалить (с подтверждением)
- [ ] Категорию с курсом удалить и архивировать нельзя: понятный отказ
- [ ] Архив: категория пропадает из выбора при создании курса, с галочкой «Показать архивные» видна

### 6.4. Курсы и зачисления (Анна)

- [ ] «Мои курсы»: поиск по названию, фильтр по категории и статусу, страницы (если курсов больше 20)
- [ ] Создать курс: ошибки у полей при пустом названии, после успеха открывается карточка курса
- [ ] В карточках видны названия категорий и имена, а не id
- [ ] Зачислить студента по email. Повторное зачисление: «Студент уже зачислен»
- [ ] Зачисление несуществующего email: ошибка у поля
- [ ] Отчислить студента: требуется подтверждение и причина. Студент сразу теряет доступ к курсу
- [ ] Вкладка «Отчисленные» показывает дату и причину
- [ ] **Конфликт редактирования:** курс открыт в двух вкладках у Анны (в каждой войти). Во вкладке 1 сохранить изменения, во вкладке 2 сохранить свои. Во вкладке 2 сообщение о конфликте, введенный текст на месте, кнопка «Загрузить актуальные данные» работает

### 6.5. Задания и сдача (Анна → студент)

- [ ] Анна создает задание. Срок в прошлом: ошибка у поля. Срок вводится по времени Алматы, подпись видна
- [ ] Студент видит задание в курсе, срок по времени Алматы
- [ ] Студент сдает работу: «Версия №1 отправлена»
- [ ] Текст короче минимума из настроек задания: ошибка у поля, версия не создана
- [ ] Повторная сдача: «Версия №2», в истории версии от новой к старой
- [ ] Задание со сроком через 1–2 минуты: после срока предупреждение «срок прошел», новая версия помечена «с опозданием»
- [ ] Задание с «Сколько версий: 1»: вторая сдача — «Достигнут предел версий»
- [ ] **Одновременная сдача:** задание открыто у студента в двух вкладках, «Отправить» нажато почти одновременно. Номера идут подряд, без повторов
- [ ] Текст с HTML (например, `<b>жирный</b><script>alert(1)</script>`) показывается как обычный текст, скрипт не выполняется

### 6.6. Оценивание и результаты

- [ ] Анна: «Оценивание» → «Ожидают оценки», самые старые сверху. Фильтр по курсу работает
- [ ] Балл больше максимального или дробный: ошибка у поля
- [ ] Оценить версию 1 студента на 50: студент в «Моих результатах» видит 50 (версия №1)
- [ ] Оценить версию 2 на 80: результат 80 (версия №2)
- [ ] Переоценить версию 1 на 60: результат остается 80, в истории версии 1 две оценки
- [ ] **Конфликт оценок:** одна работа открыта у Анны в двух вкладках. Оценка во вкладке 1 проходит, во вкладке 2 конфликт, балл и комментарий в форме сохранены
- [ ] Данияр (демо): по «Лабораторной 2» балл 20 по версии №1, версии 2 и 3 ожидают оценки
- [ ] Мария (демо): «не сдано, срок прошел» по «Лабораторной 2»

### 6.7. Реальное время (два профиля браузера)

- [ ] В шапке индикатор «онлайн»
- [ ] Анна на `/grading`, студент сдает работу: работа появляется у Анны без обновления страницы
- [ ] Анна ставит оценку: у студента оценка появляется в истории версий и в «Моих результатах» без обновления
- [ ] Посторонний пользователь в третьем окне ничего не получает (список у него не меняется)
- [ ] Остановить API (Ctrl+C): индикатор «нет связи, переподключаемся». Запустить API: «онлайн», данные перечитаны
- [ ] После «Выйти» в DevTools → Network → WS соединение закрыто

### 6.8. Ошибки и устойчивость

- [ ] Остановить API: страницы показывают «Нет связи с сервером» и кнопку «Повторить»
- [ ] Неверный адрес вида `/courses/123`: понятная страница «не найден»
- [ ] Несуществующая страница сайта: «Страница не найдена»
- [ ] **Сохранность после перезапуска:** создать курс или оценку, перезапустить API и сайт, войти снова. Данные на месте (они в MongoDB, а не в памяти)

### 6.9. Интерфейс

- [ ] DevTools → режим устройства, ширина **390 px**: главные кнопки доступны, таблицы прокручиваются внутри своего блока, формы не вылезают за экран
- [ ] Ширина **1280 px**: все аккуратно
- [ ] Только клавиатура (Tab / Shift+Tab / Enter): можно войти, перейти к курсу, сдать работу. Фокус хорошо виден
- [ ] У каждого поля есть подпись, обязательные отмечены `*`, формат подсказан
- [ ] Время подписано («время Алматы»), баллы подписаны («из 100», «б.»)
- [ ] DevTools → Network: сайт ходит на `http://localhost:4000/api/v1/...`, ошибки приходят в формате `{ error: { code, message, fields } }`

## 7. Проверка API без сайта

Файлы в `docs/http/` для расширения REST Client (VS Code) или HTTP-клиента JetBrains:

| Файл | Что проверяет |
|---|---|
| `auth.http` | регистрация, лишнее поле `role` → 400, вход, `/me`, 401 без токена |
| `courses.http` | категории, курсы, конфликт `version` → 409, зачисление, неверный id → 400 |
| `submissions.http` | задания, срок без часового пояса → 400, сдача, `number` → 400, преподаватель сдает → 403 |
| `grades.http` | кабинет оценивания, оценка, повтор с той же `version` → 409, балл вне диапазона → 400 |
